# Explicit OpenAI task runtime bootstrap

`openai-runtime.ts` provides an opt-in server-only registration entry. No startup file imports it. Trusted composition must provide executor storage, fixed HTTPS resolution, credential reading and availability capabilities, pricing callbacks, a complete AI task/model catalog, task policies, budget bindings and authenticated authorization. It cannot accept fetch, activation rights, environment discovery or caller credentials.

Preparation snapshots declarations and function capabilities, performs bounded read-only checks against the current additive migration control schema, verifies immutable active configuration and every profile/exception, checks declared budgets without reserving/releasing them, then checks credential availability without reading a secret or probing a model. The active configuration is re-read before installation. Both duplicate bundles and readiness calls retain the original capabilities and wait; failure does not install or silently reset a runtime.

Budget and agent grants are still checked per task. Catalog capabilities are mandatory even if a caller omits them. Preflight and usage pricing must match the declared tariff and currency; unavailable measured cost retains uncertainty. Readiness is a local check at registration, not a permanent model/configuration pin or a spend authorization: each execution still uses current admission, authenticated authorization, pinned dispatch and original accounting.

The tests install only in isolated VM globals with synthetic availability, catalogs, credentials, HTTPS/DNS/peer and model responses; designated PostgreSQL and its role permissions are native. This does not validate production storage, credential provenance, account model availability, actual tariffs/TLS, application startup, deployment or operational acceptance. Server startup and administrative configuration bootstrap remain uninstalled. A failed original registration requires trusted lifecycle intervention; JSON, time, hashes or a reset cannot turn it into a successful one.
